Hydraulic Lab 1.1.0 · Windows x64

복동 유압 실린더·방향밸브·릴리프를 열어 보고 조작하는 교육용 관찰 앱입니다.

설치와 실행:
Hydraulic-Lab-Setup-1.1.0.exe를 실행한 뒤 바탕화면 또는 시작 메뉴의 Hydraulic Lab을 엽니다.
운동 모형과 3D 화면을 앱에 포함하므로 Node.js·별도 서버·인터넷 없이 사용할 수 있습니다.
이 배포 설정에는 코드 서명이 없으며 Windows의 게시자·평판 경고가 표시될 수 있습니다.
자동 업데이트는 없습니다. 제공처와 함께 제공된 SHA-256을 확인하세요.
WebGL2를 지원하는 그래픽 환경이 필요합니다. 실제 확인한 Windows·GPU·화면 배율은 해당 릴리스 기록을 확인하세요.

처음 해 보기:
1. '같은 유량, 다른 속도' 실험을 선택하고 재생합니다.
2. '다음 조작'을 따라 전진 끝까지 이동한 뒤 후진하고, 실제로 확인한 결과를 비교합니다.
3. '속도와 힘의 한계', '움직임이 멈춘 뒤의 압력'도 방향과 재생을 직접 조작하며 관찰합니다.
4. '안내 다시 시작'은 해당 실험의 초기 조건으로 돌아갑니다. '자유 탐구로 전환'은 안내를 끝내고 현재 관찰을 이어갑니다.
5. 부품을 선택한 뒤 '선택 부품 가까이 보기'로 살펴보고, '전체 보기'로 돌아옵니다.
3D를 크게 본 상태에서도 '안내·결과 보기'로 안내에 접근할 수 있습니다.
3D는 드래그로 회전, 오른쪽 드래그로 이동, 휠이나 두 손가락으로 확대합니다. 이름표·회로도·부품 목록으로 부품을 선택할 수 있습니다.

관찰의 의미:
전진·중립·후진 명령으로 유로를 바꿉니다. 같은 펌프 유량에서 로드측 면적이 작아 후진이 더 빠릅니다.
중립은 펌프의 P→T 순환이며 실린더 A·B는 고립되어 마지막 압력을 유지합니다.
압력 색과 실제 유량 화살표를 구분하세요. 압력이 남아 있어도 액실에 유량이 없을 수 있습니다.
펌프 유량·릴리프 압력·저항 하중을 바꾸면 같은 위치에서 새 조건 실험을 시작합니다.
이는 장비의 실제 감압 과정이 아니며 경과 시간·에너지·누적량이 초기화됩니다.
관찰 일시정지는 계산 시간 정지이며 펌프 전원 차단이 아닙니다.
펌프 유량은 모형의 실제 속도를 바꾸고 관찰 속도는 화면에서 모형 시간이 흐르는 배율을 바꿉니다.
압력 제한 설정은 상한입니다. 움직일 때 실제 압력은 하중과 방향별 실린더 면적으로 정해집니다.
부품을 선택하면 해당 액실·포트·배관의 현재 계산값이 나옵니다. 크게 보기에서도 부품 선택과 계산값 확인이 가능합니다.
'압력에서 힘·동력으로'에서 양쪽 힘의 부호와 합, 부하 동력과 릴리프 소산을 비교하세요.
중립의 잔압은 유량이나 일률이 아닙니다. 0 W인 무손실 순환에서도 펌프 유량은 흐를 수 있습니다.

이 모형은 수평 저항 부하·비압축성·누설 없음·관성 없음의 준정상 회로입니다.
중력 하강·압력 파동·압축성·누설·열·마모나 실제 장비의 안전성을 계산하지 않습니다.
분해 위치와 릴리프 포핏의 표시 움직임은 구조 관찰용입니다.

파일과 복귀:
실험 저장(Ctrl+S): 위치·압력·시간·누적 에너지·통과 체적과 화면·시점을 JSON에 보관합니다. 기본 파일명은 hydraulic-lab-YYYY-MM-DD.json이며 저장 대화상자에서 바꿀 수 있습니다.
실험 열기(Ctrl+O): 전체 기록을 검증한 뒤 복원합니다. 취소하거나 잘못된 파일이면 현재 관찰을 유지합니다.
10 MiB 이하의 JSON과 단일 UTF-8 BOM을 지원합니다. 새로운 저장 버전의 원문은 보호합니다.
폴더·연결 파일 대신 원래 일반 JSON 파일을 선택하세요. 파일 읽기는 원본을 바꾸지 않습니다.
저장은 임시 파일을 완성한 뒤 목적 파일로 교체합니다. 파일 작업이 끝난 뒤 종료하세요.
중요한 관찰은 자동 저장 외에 별도 파일로 보관하세요. 복원할 때는 일시정지 상태로 시작합니다.
학습 안내의 단계·완료 결과는 현재 세션 전용으로 파일에 저장하지 않습니다. 파일 열기·새 실험·앱 재시작은 안내를 종료합니다. 직전 실험 되돌리기는 현재 세션의 안내 상태도 복구합니다.
손상되거나 새 버전인 자동 저장은 원문을 유지하고 자동 덮어쓰기를 멈춥니다. '원문 내려받기'로 원문을 보관하고 현재 관찰은 다른 실험 파일에 저장하세요.

새 실험: Ctrl+N
운동 시작/일시정지: Ctrl+Shift+P
3D 크게 보기: Ctrl+Shift+F
전체 화면: F11
사용 안내: F1
저장 폴더: 도움말 > 저장 폴더 열기 (%APPDATA%\Hydraulic Lab)
프로그램 정보: 도움말 > 프로그램 정보
제거: Windows 설정 > 앱 > 설치된 앱 > Hydraulic Lab
