    QUICK GUIDE

    유압을 처음 만난다면

    1. 전진 또는 후진을 선택하고 재생합니다.

      방향밸브가 P·A·B·T를 연결합니다. 같은 유량이라도 로드측 면적이 작아 후진이 더 빠릅니다.

    2. 멈추어도 압력과 유량을 따로 읽습니다.

      중립은 P→T 순환과 A·B 고립입니다. 행정 끝이나 압력 한계에서는 펌프 유량이 릴리프로 돌아갑니다.

    3. 절개와 분해로 연결을 확인합니다.

      드래그로 회전, 오른쪽 드래그로 이동, 휠이나 두 손가락으로 확대합니다. 이름표나 회로 부품을 누르면 설명이 바뀝니다.

    4. 새 조건은 같은 위치의 새 실험입니다.

      시간·압력·누적 에너지를 초기화합니다. 되돌리기는 이전 실험을 복원합니다. 관찰 속도는 펌프 설정을 바꾸지 않습니다.

    이 모형에서 알 수 있는 것

    면적·유량·속도·힘·압력 제한·에너지 수지의 관계를 관찰합니다. 실제 밸브 전환 과도, 압축성, 누설, 마찰 변화, 온도와 장비 안전성은 해석하지 않습니다. 부하는 수평 이동을 거스르는 저항이며 매달린 하중이 아닙니다. 한계 압력과 필요한 압력이 같을 때는 정지로 정의합니다.
