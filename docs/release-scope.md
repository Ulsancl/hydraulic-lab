# 공개 범위와 완료 기준

Hydraulic Lab의 공개 범위는 일반 사용자가 복동 유압 실린더·방향 밸브·릴리프를 분해 관찰하고 조건을 바꾸어 원리를 비교하는 Windows x64 교육 앱이다. 이 문서는 배포 후보가 충족해야 할 기준이다. 특정 후보의 통과 결과는 해당 릴리스 기록에 버전·소스 커밋·설치파일 SHA-256과 함께 남긴다. 기준이 문서에 있다는 사실만으로 검증 완료를 뜻하지 않는다.

## 사용자 경험

| 완료 기준 | 확인 방법 |
|---|---|
| 설치 후 아이콘으로 오프라인 실행 | 실제 NSIS 설치, 바탕화면·시작 메뉴의 EXE 및 아이콘 대상, 앱 버전과 ASAR 일치 확인 |
| 세 실험에 다음 조작과 확인 결과가 명시됨 | 속도·힘 한계·중립 실험에서 실제 방향 조작과 시간 진행으로 단계 확인·결과 수치를 검사. 다시 시작·자유 탐구와 직전 실험 되돌리기도 확인 |
| 조작 의미가 일관됨 | 방향과 재생/일시정지, 펌프 유량과 관찰 배율, 실제 압력과 릴리프 상한을 문구·계측판·회로·3D에서 구분 |
| 구조가 보이고 조작에 접근할 수 있음 | 조립·절개·분해 및 피스톤·스풀·릴리프 확대의 실제 이미지 검토. 1024px·390px 화면에서 필수 조작, 안내·파일·도움말 접근 확인 |
| 선택과 시점 조작이 예상대로 동작 | 부품 선택은 시점을 임의로 바꾸지 않고 명시적인 확대·전체 보기로 이동. 관찰 모드·레이어·이름표·압력 색·유량 화살표 확인 |
| 일시정지 시 불필요한 반복 렌더링 억제 | 실제 렌더 프레임 수로 정지 중 idle 상태와 조작 후 갱신 확인 |

## 계산과 데이터

순수 검사는 독립 면적·속도·힘 관계, 전진/중립/후진의 유량 수지, 압력 한계, 부분 프레임 행정 끝과 에너지, 누적 체적, 설정 변경, 불규칙 시간 간격을 확인한다. 형상 체적과 계산 체적이 일치하고 배관 경로가 밸브 내부를 잘못 관통하지 않아야 한다. 계산 가정은 [모형 문서](model.md)를 기준으로 한다.

브라우저와 앱에서는 같은 상태가 3D·회로도·계측판에 반영되는지 확인한다. 실험 JSON의 설정·명령·위치·압력·시간·누적량·보기·카메라를 왕복 복원하고 같은 다음 시간 간격의 결과를 비교한다. 재실행과 파일 열기는 일시정지 상태여야 한다. 안내 진행은 현재 세션 전용이며 저장 파일에 포함하지 않는다.

취소, 손상 JSON, 지원하지 않는 새 형식, 10 MiB 초과, BOM, 디렉터리와 연결 파일, 저장 실패를 다룬다. 실패한 입력은 현재 관찰을 부분 변경하지 않아야 한다. 손상·새 버전 자동 저장의 원문을 덮어쓰지 않고 별도 파일로 보관할 수 있어야 한다. 모든 자동 검사는 합성 파일·격리 프로필을 사용하며 실제 사용자 자료를 수정하지 않는다.

## Windows와 배포 자료

1. 고정 의존성의 순수 검사·빌드·브라우저·소스 앱·독립 패키지 앱 검사가 통과해야 한다. GitHub CI는 패키징과 artifact 보관을 수행하되 Release는 자동 게시하지 않는다.
2. 실제 설치 EXE로 메뉴·도움말·파일 작업·종료를 검사한다. 설치 폴더·바로가기·표시 버전·ASAR·라이선스와 안내 자료를 확인한다. 패키지 EXE의 검사만으로 실제 설치가 확인됐다고 기록하지 않는다.
3. Windows 화면 배율과 임의 창 위치에서 저장·재시작을 반복해 크기나 위치가 누적 변화하지 않는지 확인한다. 사용한 배율과 그래픽 장치, 실제 WebGL renderer, 정상 종료와 잔여 프로세스 결과를 남긴다.
4. 이전 버전 호환성을 주장하는 경우 실제 이전 버전의 비기본 실험·카메라·자동 저장으로 확인한다. 사용자 기본 프로필은 검사 전후 유지해야 한다. 새 후보에서 이미 통과한 코드가 그대로라는 근거를 사용하는 경우 파일 해시 일치와 실제 재실행 여부를 구분한다.
5. 공개 저장소에는 앱 소스·필요 자산·고지·고정 의존성만 포함한다. 사용자 프로필·합성 실험·로컬 감사 자료·이전 앱의 비공개 이력을 포함하지 않는다. 공개 다운로드 후 설치파일 해시가 검증한 파일과 일치하는지 확인한다.

## 릴리스 기록에 남길 것

버전과 커밋, 설치파일 이름·크기·SHA-256, 실제 검사 환경과 수행한 검사 결과, 서명 여부, 알려진 제한을 기록한다. 이전 개발 버전의 결과를 새 코드의 통과 결과로 대신하지 않는다. 미수행 항목, CI 패키지 실행과 실제 설치 실행, 문서만 바뀌어 동일한 실행 파일을 재사용한 경우를 구별한다.

이전 검사 결과와 이미지는 당시 후보의 근거다. 새 UI나 형상을 추가하면 영향을 받는 실제 조작·이미지 검사를 갱신한다. 결과가 확인되지 않은 항목을 완료로 표시하지 않는다.

## 명시적인 제외 범위

실제 장비 성능·안전성·정비 판단, 중력 하강, 압축성·관성·누설·마찰·압력 손실·온도·수명 계산은 포함하지 않는다. 대표 치수와 이상화된 릴리프 동작은 제조사 실측 모형이 아니다. 자세한 제한은 [모형](model.md)과 [참고 자료](references.md)를 따른다.

코드 서명과 자동 업데이트는 구성하지 않았다. 검증하지 않은 Windows·GPU·원격 접속 환경의 호환성이나 유료 지원·응답 시간은 보장하지 않는다. 판매·지원·재배포 권한은 별도 결정이며 앱 자체의 UNLICENSED 표기는 유지한다. 데이터 처리와 신고 범위는 [개인정보](privacy.md), [지원 안내](support.md), [외부 고지](THIRD-PARTY-NOTICES.md)를 따른다.
