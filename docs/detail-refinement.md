# Hydraulic Lab 상세 관찰 개선

확인일: 2026-10-02. 기존 복동 실린더·탠덤 센터 방향밸브·고정 유량 펌프·릴리프 회로의 작동점을 부품별로 읽는 개선이다. `hydraulic-quasistatic-1`과 기존 실험 상태·저장 형식은 유지한다. 관성·압축성·손실·효율·온도 모형을 추가하지 않는다.

## 중립·막힘·이동을 읽는 방법

중립은 P→T 순환과 A·B 고립이다. 양실 압력과 그 압력이 만드는 힘은 남을 수 있지만 양실 유량과 실린더 전달 동력은 0이다. 이상 회로의 잔압을 압축 저장 에너지나 가상의 감압 곡선으로 바꾸지 않는다.

힘이 부족하거나 행정 끝이면 속도는 0이고 펌프 전량이 릴리프로 흐른다. P 분기 앞의 유량은 유지되지만 방향밸브 P 포트로 들어가는 유량은 0이다. 릴리프 유량은 방향밸브 T 포트 바깥에서 합류한다. 후진 중에는 넓은 캡측에서 나오는 복귀 유량이 공급 유량보다 클 수 있으며, 이는 누설이 아닌 면적과 체적의 관계다.

현재 순유압력은 `pA Ac − pB Ar`, 방향별 힘 한계는 설정 압력에 각 유효 면적을 곱한 크기다. 수평 저항 부하는 이동을 거스르며 정지 중에는 설정값까지 반력을 제공한다. 끝 지지의 반력과 개별 부품의 응력을 새로 분배해 계산하지 않는다.

이동 중 도달 예상은 남은 거리 / 현재 속력이다. 중립·압력 제한·행정 끝에서는 값을 비워 ‘이동 중 아님’으로 읽는다. 관찰 일시정지와 재생 배율은 모형의 회로 명령이나 작동점 값과 별개다.

## 수지와 검증

캡·로드·탱크 체적의 합, 세 체적 변화율, 공급 분기·복귀 합류, 액실 유압 동력과 순유압력×속도, 순간 동력과 누적 에너지 수지를 원래 숫자로 대조한다. 끝점에 닿는 구간은 기존 계산의 이동/릴리프 구간별 적분을 유지한다. 릴리프 소산을 온도로 바꾸거나 0/0 동력 비율을 효율로 표시하지 않는다.

새 검증은 `tests/detail-model.test.mjs`에 있다. 시간 진행에서 얻은 체적 차분, 동일 공급량의 전진·후진 거리와 반환 체적, 정확한 끝 도달, 끝 전후의 부하 일·릴리프 소산, 중립 잔압, 압력 경계와 무부하 이동, 입력 양끝의 명령 이력, 모든 34개 부품의 단위·비변경성을 검사한다. 상세한 필드·수식·가정은 [계산 모형](model.md)에 기록했다.
