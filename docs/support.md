# 문제 해결과 신고

이 앱의 지원 범위는 유압 원리를 관찰하는 프로그램의 설치·실행·파일·화면 문제입니다. 실제 장비의 고장 진단, 안전 검증, 회로 설계 승인 또는 현장 정비 지침은 제공하지 않습니다. 유료 지원, 보증 조건, 특정 응답 시간은 현재 문서에서 약속하지 않습니다.

## 먼저 확인할 것

| 증상 | 확인 방법 |
|---|---|
| 실린더가 움직이지 않음 | 재생 중인지 확인하고 전진·후진을 선택합니다. 중립, 행정 끝, 압력 한계 정지는 정상 상태입니다. 계측판의 상태와 릴리프 유량을 확인하세요. |
| 압력 제한 값을 바꿔도 화면 압력이 그대로임 | 제한은 상한입니다. 실제 압력은 방향별 면적과 저항 하중으로 정해집니다. 편집한 조건은 **새 조건 적용** 뒤에 반영됩니다. |
| 화살표가 없는데 압력 색이 남음 | 중립에서는 A·B 액실이 고립되어 압력이 남고 실린더 유량은 0입니다. 압력과 유량은 다른 값입니다. |
| 부품이 화면 밖으로 나감 | **전체 보기**를 누릅니다. 특정 부품은 선택 후 **선택 부품 가까이 보기**로 봅니다. 분해 간격을 줄여 비교할 수도 있습니다. |
| 3D 화면이 검거나 표시되지 않음 | 앱 버전과 그래픽 드라이버, WebGL2 지원 환경을 확인합니다. 원격 데스크톱·가상 머신에서는 그래픽 환경이 달라질 수 있습니다. 지원 여부를 확인하지 않은 환경에서의 동작을 보장하지 않습니다. |
| 실험 파일을 열 수 없음 | Hydraulic Lab JSON인지, 10 MiB 이하인지 확인합니다. 폴더·연결 파일 대신 원래 일반 파일을 선택하세요. 잘못된 수치나 지원하지 않는 형식은 보정해 여는 대신 거부합니다. 원본을 보관한 채 오류 내용을 기록하세요. |
| 더 새로운 버전의 파일 또는 자동 저장 안내 | 해당 파일을 만든 버전 이상에서 열어야 합니다. 원본을 직접 편집하거나 현재 버전의 빈 실험으로 덮어쓰지 마세요. 보호 중인 자동 저장은 **원문 내려받기**로 별도 보관할 수 있습니다. |
| 자동 저장 실패 안내 | 현재 실험을 다른 쓰기 가능한 위치의 파일로 저장하세요. 저장 공간이나 폴더 권한을 확인합니다. 파일 열기·저장 취소는 현재 관찰을 지우지 않습니다. |
| Windows 게시자·평판 경고 | 이 배포 설정은 서명되지 않았습니다. 배포 출처와 SHA-256을 확인하세요. 서명 부재나 해시 일치가 안전성 보증을 의미하지는 않습니다. |

## 신고할 정보

배포 저장소의 **Issues**를 이용할 수 있을 때 다음 내용을 적어 주세요. 해당 릴리스에 별도 연락처가 있으면 그 안내를 따릅니다. 앱이 자동으로 신고 내용을 보내지는 않습니다.

1. **도움말 → 프로그램 정보**에 표시된 버전과 설치파일 출처.
2. Windows 버전, 화면 해상도·배율, 그래픽 장치와 드라이버 정보. 화면 문제라면 원격 접속 여부도 포함합니다.
3. 처음 시작한 상태부터 문제까지의 조작 순서, 예상 결과와 실제 결과, 표시된 오류 문구.
4. 재현에 꼭 필요한 경우의 실험 JSON 또는 화면 이미지. 첨부 전 내용을 확인하고 개인 경로·다른 창·불필요한 개인 정보를 제외하세요.

공개 Issues의 내용은 다른 사람도 볼 수 있습니다. 전체 앱 저장 폴더나 사용자 폴더를 올릴 필요는 없습니다. 손상된 원문이 필요하더라도 사용자가 내용을 확인한 뒤 선택적으로 첨부합니다. 문제 신고만으로 수정 일정이나 특정 기능 추가를 보장하지는 않습니다.
