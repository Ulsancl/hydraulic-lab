# Hydraulic Lab 대표 구조와 좌표

Hydraulic Lab은 수평 복동 실린더와 탠덤 센터 방향밸브를 관찰하는 자체 대표 회로다. 고정 유량 펌프, 압력 제한 릴리프, 탱크, 흡입망, 복귀 필터를 연결한다. 현재 문서는 순수 기하와 수치 모델의 공통 기준이며 3D 화면·설치 검증이 끝났다는 뜻은 아니다.

## 실린더와 체적

내부 단위는 m·Pa·m³/s·N이다. +X가 실린더 전진, +Y가 위, +Z가 관찰자 쪽이다. 실린더 축은 y=0.235 m, z=0이고 보어 60 mm, 로드 지름 35 mm, 행정 300 mm, 피스톤 두께 18 mm를 사용한다.

캡 내면 x=-0.280 m, 글랜드 내면 x=0.050 m 사이에서 피스톤 중심이 x=-0.265+변위로 움직인다. 양 끝에는 각각 6 mm의 최소 액실 길이가 남는다. 데드볼륨은 이 실제 원형·환형 공간으로부터 정하며 그림 밖에 별도 체적을 더하지 않는다. 로드측 체적에서는 로드가 차지한 원통을 뺀다. 피스톤·로드 끝·부하 연결점은 함께 이동하고 양실의 고정 피팅·글랜드 씰·가이드는 이동하지 않는다.

총 실린더 액체 체적은 전진하면서 로드 단면적×변위만큼 증가한다. 탱크의 오일 체적은 같은 양만큼 감소한다. 3D에 전달할 탱크 높이도 모델 체적과 고정된 탱크 내부 면적에서 구한다. 탱크 그림의 빈 공간이나 임의 입자 개수로 체적을 대신하지 않는다.

## 방향밸브의 실제 연결 형상

외부 포트는 P(공급), A(캡측), B(로드측), T(복귀) 네 개다. 몸체 안의 환형 갤러리는 T1–A–P–B–T2 순서다. T1과 T2는 몸체 내부에서 하나의 외부 T 포트로 합쳐진다.

스풀에는 두 외곽 홈과 세 랜드, 별도의 중립용 내부 축방향 바이패스를 둔다. 바이패스의 세 방사 구멍은 중립에서만 P 및 두 T 갤러리와 겹친다. 외곽 홈·몸체 창·방사 구멍의 축방향 겹침으로 열린 포트 연결을 도출한다.

| 위치 | 열린 연결 | A/B 의미 |
|---|---|---|
| 전진, 스풀 +10 mm | P–A, B–T | 캡측 공급, 로드측 복귀 |
| 중립, 스풀 0 mm | P–T | A와 B는 각각 고립 |
| 후진, 스풀 -10 mm | P–B, A–T | 로드측 공급, 캡측 복귀 |

이 구조는 원리를 설명하기 위한 자체 제작 형상이다. 실제 밸브 제품의 가공 공차·내부 누설·비례 개구나 이동 중 과도응답을 해석하지 않는다. 모델이 세 위치로 즉시 전환할 때 기하도 같은 위치를 사용한다. 중립에서 고립된 실린더 압력을 0으로 바꾸는 것은 기하의 역할이 아니다.

## 회로와 관찰 정보

탱크 흡입망에서 펌프로 연결되고, 펌프 출구는 방향밸브 P와 릴리프 입구로 나뉜다. A/B 배관은 각 액실의 고정 피팅에 연결된다. 방향밸브 T와 릴리프 복귀가 합쳐져 하나의 복귀 필터를 지난 뒤 탱크로 돌아간다. 모든 배관의 시작·끝은 부품과 공유하는 포트 좌표에서 생성한다.

각 배관에는 모델 snapshot의 압력 포트와 유량 필드가 연결된다. A/B 유량은 실린더로 들어갈 때 양수, 나올 때 음수다. 공통 복귀 필터는 방향밸브 복귀와 릴리프 복귀의 합을 받는다. 압력 색과 흐름 화살표는 별개 정보이며, 높은 압력만으로 움직임이나 큰 유량을 그리지 않는다.

분해와 표시 레이어는 물리 상태와 별개다. 부품 선택 ID는 장면·부품 목록·회로도·저장 파일이 공유한다. 선택이 카메라를 바꾸거나 모델의 압력·위치를 바꾸어서는 안 된다. 부품명은 수평을 유지하고, 분해 상태의 내부 유로를 표시할 때는 조립 상태의 대표 회로라는 안내가 필요하다.

## 펌프와 릴리프의 가공 구조

펌프의 두 축은 30 mm 떨어져 있다. 하우징 내부는 각 축을 중심으로 하는 반지름 18.2 mm의 두 원형 보어를 연결한 공간이다. 중심 하나만 사용하는 원통 구멍과 달리 두 기어의 끝이 벽을 침범하지 않는다. 앞 덮개를 제거하는 절개 상태에서는 실제 내벽·분할면·뒤 덮개와 두 축의 청동 부싱이 보이고, 분해 상태에서는 앞 덮개와 고정 볼트가 함께 분리된다. 덮개의 축 구멍과 볼트 구멍은 막힌 원판 위에 그린 표시가 아니라 열린 공간이다.

기어의 모따기를 포함한 실제 메시와 보어의 다각형 단면으로 계산한 회전 반경 여유의 하한은 약 0.683 mm이고, 앞뒤 덮개까지의 축방향 여유는 각각 0.300 mm다. 이는 이 대표 형상의 표시 치수이며 제품 가공 공차나 실제 펌프 누설량을 뜻하지 않는다. 두 12치 기어는 기존의 반대 회전과 반 피치 위상을 유지한다. 치형은 원리 관찰용 다각형으로, 생산용 인벌류트 치형·무간극 접촉·토출 맥동·치간 유체 체적을 해석하지 않는다. 외부 포트와 배관 연결 좌표도 기존 회로를 유지한다.

릴리프 시트와 포핏은 같은 원뿔 기울기의 접촉면을 사용한다. 반지름 4.0–6.5 mm의 접촉 구간은 닫힘 상태에서 일치하고, 우회 유량이 있을 때만 포핏이 표시용으로 3.5 mm 올라간다. 시트 바깥 반지름 10 mm는 몸체 안의 실제 확대 포켓에 들어가며, 위아래 9 mm 보어의 단차가 시트를 지지한다. 절개 상태에서는 시트 앞쪽 절반도 제거해 맞닿은 원뿔 면과 열린 틈을 볼 수 있고, 분해 상태에서는 이 절반이 몸체와 같은 방향으로 분리된다. 포핏은 전체 형상을 유지한다. 가는 유로 표시는 열린 틈을 지나도록 배치한다. 스프링의 위쪽 끝은 고정되고 아래쪽 끝이 포핏과 같은 양만큼 움직인다. 이 개폐 표시를 실제 연속 개도·스프링 힘·유효 유로 면적 계측값으로 사용하지 않는다.

가공 평면과 주조면은 서로 다른 거칠기와 미세 표면을 사용한다. 절개 경계는 날카롭게 유지하고 새 보어·원뿔 표면의 둘레 방향 노멀은 부드럽게 연결한다. 미세 표면은 충분히 샘플링한 텍스처와 밉맵을 사용하며, 실제 치수·유압 상태를 변경하지 않는다. 펌프 가까이 보기는 탱크 벽 위로 접근하도록 맞춘다. `sceneDebug().mechanical`의 기어 축·덮개 간격과 시트 접촉점은 실제 렌더 메시에서 확인하며, 펌프 가까이 보기의 표본 시선 검사로 기어가 다른 부품에 가리지 않는지도 확인한다.

## 순수 기하 API

- `cylinderGeometry(positionM)`: 피스톤·로드·부하 연결점, 양실 경계와 실제 체적, 이동/고정 씰, 고정 A/B 피팅.
- `tankGeometry(volumeM3)`: 탱크 실제 수위와 액체 경계.
- `spoolGeometry(command)`: 몸체 창·랜드·홈·내부 구멍 및 이 겹침에서 도출한 포트 연결. 축 방향 수치는 `axisOrigin`을 원점으로 하는 로컬 X 좌표다.
- `PORTS`, `CIRCUIT_ROUTES`, `getCircuitRoutes()`: 공통 피팅과 회로 선. route의 양의 유량 방향은 `from→to`다.
- `COMPONENTS`: 고정 부품 ID·이름·설명·재질 목록.

이 모형은 비압축성·누설 없음·관성 없음의 관찰용 이상 회로다. 실제 장비의 설계·정비, 부하 유지 안전성, 캐비테이션·마모·유온을 판정하지 않는다. 릴리프 포핏과 스프링을 시각화하더라도 해석하지 않은 개도나 스프링 힘을 실제 계측값으로 제시하지 않는다.
