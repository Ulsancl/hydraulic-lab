# 저장 위치와 개인정보

Hydraulic Lab은 로컬 관찰 앱입니다. 계정, 로그인, 클라우드 동기화, 광고, 사용 통계 또는 실험 파일을 전송하는 기능이 없습니다. 설치 앱은 번들에 포함한 자산을 사용하며 앱 내부의 HTTP(S) 요청과 외부 페이지 이동을 차단합니다. 인터넷 없이 모형 계산·3D 관찰·파일 저장을 사용할 수 있습니다.

이 설명은 앱 자체의 기능에 대한 것입니다. Windows의 진단 기능, 백신 검사, 사용자가 선택한 클라우드 동기화 폴더나 GitHub에 직접 올린 첨부파일은 각 서비스의 설정을 따릅니다.

## PC에 남는 데이터

| 데이터 | 위치와 내용 |
|---|---|
| 자동 저장과 화면 복원 | 기본 `%APPDATA%\Hydraulic Lab` 안의 Electron 사이트 저장소에 실험 JSON을 보관합니다. 설정·명령·위치·압력·시간·누적량·보기·카메라를 포함합니다. |
| 창 위치와 크기 | 같은 앱 저장 폴더의 `window.json`에 보관합니다. |
| 실행 진단 | 같은 폴더의 `desktop.log`에 시작 버전·시각과 시작/화면 오류를 기록할 수 있습니다. 오류에는 로컬 경로가 포함될 수 있으며 자동 전송하지 않습니다. |
| 손상되거나 새 버전인 자동 저장 원문 | 기존 저장 키를 그대로 유지합니다. 가능하면 별도 원문 보관 키에도 복사하며 자동 덮어쓰기를 막습니다. |
| 그래픽·실행 캐시 | Electron이 같은 앱 저장 폴더 아래에 생성할 수 있습니다. 실험 파일과 별개입니다. |
| 직접 저장한 파일 | 사용자가 저장 대화상자에서 지정한 위치의 JSON입니다. 기본 제안 이름은 `hydraulic-lab-YYYY-MM-DD.json`입니다. |

자동 저장은 버전별 백업 목록이 아닙니다. 정상적인 다음 관찰이 앞선 자동 저장을 갱신하므로 중요한 실험은 **실험 저장**으로 별도 보관하세요. 원문 보호 안내가 표시되면 **원문 내려받기**로 원문을 먼저 보관하고 현재 작업은 다른 파일에 저장합니다. 앱은 문제 신고 파일을 자동으로 업로드하지 않습니다.

웹 개발판은 접속한 브라우저의 해당 사이트 저장소를 사용합니다. Windows 설치 앱과 웹 개발판, Engine Lab 등 다른 앱의 자동 저장은 서로 공유하지 않습니다. JSON 파일을 직접 저장하고 열어서 옮길 수 있습니다.

## 데이터 확인과 제거

앱 메뉴의 **도움말 → 저장 폴더 열기**로 앱 저장 폴더를 확인할 수 있습니다. 업데이트와 일반 제거는 이 폴더를 유지하도록 구성되어 있습니다. Windows에서 앱을 제거해도 직접 저장한 JSON은 지우지 않습니다.

자동 저장까지 없애려면 필요한 실험과 보호 중인 원문을 먼저 다른 위치에 보관하고 앱을 완전히 닫은 뒤, 확인한 Hydraulic Lab 저장 폴더를 직접 정리하세요. 이 작업은 자동 저장·원문 보관·창 설정을 함께 없애므로 복구용 실험 파일이 필요합니다. 다른 앱의 폴더를 정리할 필요는 없습니다.

개발·검사 전용 `HYDRAULIC_LAB_DATA_DIR`가 설정되어 있으면 지정한 절대 경로가 저장 폴더가 됩니다. 배포 앱을 일반 실행할 때는 이를 설정할 필요가 없습니다. 자동 검사는 작업 폴더 안의 별도 합성 프로필을 사용합니다.
